# 참고자료 정리

사용자가 제공한 참고자료와, 그 자료가 이 프로젝트에서 어떻게 쓰였는지 정리했다.

## 1. 국립창원대 AI Agent 해커톤 주제 안내 (PDF)

파일: [국립창원대 AI Agent 해커톤 주제 안내.pdf](국립창원대%20AI%20Agent%20해커톤%20주제%20안내.pdf) (14쪽, CWNU SW-DNA² Global Frontier Program)
문의: cwnusw@changwon.ac.kr

### 요약

- 주제: **제조 품질 AI Agent**. 기업이 직접 고른 현장 문제 3가지.
- 핵심 원칙: 완전 자동화보다 **작업자가 신뢰할 수 있는 보조 Agent**.
- Agent 의 정의: 질문에 답만 하는 챗봇이 아니라, **정해진 업무 절차를 따라 도구를 호출하고 결과물을 만드는 시스템**.
  ① 본다(비전 모델·문서 파싱) → ② 찾는다(RAG·DB 조회) → ③ 판단한다(규칙 엔진 + LLM) → ④ 작성한다(템플릿 + LLM) + Human-in-the-loop.
- 세 주제는 하나의 품질 흐름(생산·외관검사 → 출하·Spec 검사 → 고객 Complaint) 위에 있고, **주제 간 연계도 환영**.

| 주제 | 현장 애로사항 | 최종 산출물 | 제공 자료 |
|---|---|---|---|
| **01 부품 불량 사진 분석** ← 우리 주제 | 외관불량(Scratch, Dent, Burr 등) 확인과 보고서 작성에 시간 소요 | 불량 분석 보고서 | 불량 사진 샘플, 불량 유형 정의서, 보고서 양식 |
| 02 제품 검사 Spec 자동판정 | 고객사마다 검사기준이 달라 판단 어려움 | 검사성적서 | 고객사 검사기준서 샘플, 측정 데이터 샘플, 검사성적서 양식 |
| 03 고객 불만 대응 | Complaint 접수 후 자료 검색·답변 작성 시간 소요 | 고객 회신서 초안 | 과거 Complaint 사례, 불량 이력 데이터, 회신서 양식 |

### TOPIC 01 상세

- 워크플로우: STEP 1 사진 분석(불량 영역 찾기·위치 표시) → STEP 2 불량 유형 선택(제안 후 작업자 선택) → STEP 3 원인 후보(유형·공정 정보로) → STEP 4 조치 방법(원인별 조치·재발 방지) → STEP 5 보고서
- 입력: 부품 외관 사진(스마트폰·검사 카메라), 품번·공정 등 부품 정보
- 출력: 불량 위치가 표시된 이미지, 유형·원인 후보·조치가 담긴 불량 보고서
- 기술 힌트: 이미지 분류·검출·세그멘테이션 모델 또는 멀티모달 LLM, 불량 유형별 원인·조치 지식베이스(RAG), 보고서 양식 자동 채우기
- 도전 포인트: 적은 불량 샘플로 학습(증강·Few-shot), 판정 근거 시각화, 한국어·베트남어 보고서

### 이 프로젝트에 반영한 방식

| 안내서 내용 | 반영 |
|---|---|
| 검출·세그멘테이션 모델 | PCB 검출 모델, 금속 표면 세그멘테이션 모델 |
| 원인·조치 지식베이스 | `knowledge/defect_taxonomy_pcb.yaml` |
| 작업자 확인 | 정상 / 재검 / 불량 3단계 판정, 즉시 조치는 사람이 수행 |
| 판정 근거 시각화 | 박스·마스크 + 신뢰도 표시, 결함 확대 이미지 |
| 제공 자료(정의서·양식) | 아직 받지 않음 → 받으면 taxonomy 와 보고서 양식 교체 |
| 주제 연계 | 금속 데이터의 검사자 OK/NG 정보(`results/msdd/meta.csv`)는 TOPIC 02(기준 판정)와 연결 가능 |

## 2. 데이터셋 (모두 Roboflow Universe, **CC BY 4.0** — 사용 시 출처 표기 필요)

원본의 `data.yaml`, `README` 는 [datasets/](datasets/) 폴더에 있다.

| 이름 | 출처 | 규모 | 클래스 | 이 프로젝트에서 |
|---|---|---|---|---|
| PCB_dataset | `bare-pcb-defects/obj-detection-pcb-defects-yolov8` v3 | 9,666장, 640×640, 증강 없음 | falsecopper, missinghole, mousebite, opencircuit, pinhole, scratch, shortcircuit, spur | 재분할(`pcb_v2`) 후 **채택 모델** 학습 |
| PCB_Project v8 | `pcb-190b5/pcb_project-6oquz` v8 | 4,976장(train 만), 416×416, 원본 1장당 5개 증강 | Pinhole, Scratch, missing_hole, mouse_bite, open_circuit, short, spur, spurious_copper | 재매핑해 병합(`pcb_v3`), 성능 하락으로 **미채택** |
| MSDD v9 | `msdd/msdd-prompt-learning-qjz4o` v9 | 1,495장, 512×512, 증강 없음 | Dark Spot, Fold, Normal, Oxidation, Porosity, Scratch, Stain | Normal 제거·부품 단위 재분할(`msdd_v1`) 후 금속 모델 학습 |

- PCB 두 데이터셋은 파일명 패턴으로 보아 공개 데이터셋 **PKU-Market-PCB**(북경대, 결함 6종 합성 데이터) 를 기반으로 pinhole·scratch 를 추가한 것으로 보인다. 같은 원본 사진을 공유한다.
- PKU-Market-PCB 원본에는 결함 없는 템플릿 이미지가 포함된 것으로 문헌에 나오지만, 배포처(Baidu 클라우드)를 통해서만 받을 수 있어 확보하지 않았다.
  - 데이터셋 논문: *A PCB Dataset for Defects Detection and Classification*, arXiv:1901.08204
  - 배포 페이지: https://robotics.pkusz.edu.cn/resources/datasetENG
