# 03. 성능 결과

모든 수치는 **학습·검증에 쓰지 않은 test 세트** 기준이다. 두 데이터셋 모두 원본 사진(또는 부품) 단위로 분할해 누수가 없다.

## 지표 읽는 법

| 지표 | 의미 |
|---|---|
| Precision | 검출한 것 중 실제 결함인 비율 (높을수록 오탐이 적음) |
| Recall | 실제 결함 중 찾아낸 비율 (높을수록 놓침이 적음) |
| mAP50 | 박스(또는 마스크)가 정답과 50% 이상 겹치면 정답으로 치는 종합 점수. 대표 지표 |
| mAP50-95 | 더 엄격하게 위치까지 맞혀야 하는 점수 |
| 사진 단위 판정 | 결함이 하나라도 검출되면 불량, 없으면 정상으로 본 정확도 (에이전트 관점) |

## 1. PCB 결함 검출 모델 — `models/pcb_v2_yolo11s.pt` (채택)

**test 980장, 결함 5,082개:** mAP50 **0.886**, mAP50-95 0.474, Precision 0.911, Recall 0.868
(val: mAP50 0.879 — test 와 비슷해 검증 세트에 과적합되지 않았다)

| 클래스 | 한글명 | Precision | Recall | mAP50 |
|---|---|---|---|---|
| falsecopper | 잔여 동박 | 0.993 | 0.958 | 0.981 |
| mousebite | 마우스바이트 | 0.972 | 0.890 | 0.920 |
| pinhole | 핀홀 | 0.910 | 0.916 | 0.908 |
| scratch | 스크래치 | 0.818 | 0.875 | 0.905 |
| opencircuit | 단선 | 0.939 | 0.835 | 0.893 |
| spur | 스퍼 | 0.974 | 0.852 | 0.890 |
| shortcircuit | 단락 | 0.869 | 0.765 | **0.797** |
| missinghole | 홀 누락 | 0.814 | 0.851 | **0.793** |

**혼동 행렬에서 알 수 있는 것** (`results/pcb/test_eval_v2/confusion_matrix_normalized.png`)
- 결함끼리 헷갈리는 경우는 거의 없다 (최대 mousebite ↔ opencircuit 3%) → 클래스 병합 불필요.
- 오류 대부분은 **놓침**: shortcircuit 12%, spur 8%, missinghole·opencircuit 6%. 단락은 치명 결함이므로 판정 기준값을 낮게 유지해야 한다.
- 오탐(배경을 결함으로)은 주로 spur, opencircuit 으로 나온다.

**한계**
- 정상 PCB 이미지가 없어 **정상 오탐률은 측정하지 못했다.** 실제 정상 보드 사진으로 꼭 확인할 것.
- 학습 데이터는 원본을 잘라 만든 640 조각이다. 큰 실사진은 결함이 작아지므로 `imgsz=1280` 이나 잘라서 추론해야 한다.
- 공개 데이터 특성상 실제 촬영 사진(조명, 각도)에서는 성능이 떨어질 수 있다.

## 2. 금속 표면 결함 세그멘테이션 모델 — `models/msdd_v1_yolo11s_seg.pt`

**사진 단위 판정 (test 150장 = 결함 125 + 정상 25)**

| 신뢰도 기준 | 불량 검출률 | 정상 인식률 | 전체 정확도 |
|---|---|---|---|
| 0.10 | 94.4% | 68.0% | 90.0% |
| **0.25 (권장)** | **93.6%** | **88.0%** | **92.7%** |
| 0.40 | 89.6% | 88.0% | 89.3% |
| 0.50 | 86.4% | 92.0% | 87.3% |

정상 이미지가 25장뿐이라 정상 인식률은 1장마다 4%p 씩 움직인다. 참고 수준으로 볼 것.

**결함 유형별 (test, 결함 384개)** — 전체 mask mAP50 **0.564**, box mAP50 0.576

| 클래스 | box mAP50 | mask mAP50 | 판단 |
|---|---|---|---|
| Stain (얼룩) | 0.995 | 0.995 | 매우 좋음 (단, test 25개뿐) |
| Dark Spot (어두운 반점) | 0.793 | 0.790 | 양호 |
| Porosity (기공) | 0.568 | 0.542 | 보통 |
| Oxidation (산화) | 0.392 | 0.415 | 부족 |
| Fold (접힘) | 0.325 | 0.360 | 부족 (학습 데이터 적음) |
| **Scratch (스크래치)** | 0.385 | **0.280** | **가장 낮음** |

**해석**
- "결함이 있다/없다" 판정은 쓸 만하지만, **유형과 영역을 정확히 맞히는 성능은 아직 부족**하다.
- 스크래치가 가장 약하다: 가공 무늬(동심원 줄무늬)와 스크래치의 경계가 애매하고, 라벨도 경계가 모호하게 그려진 경우가 많다.
- 검사자 OK/NG(파일명)와 비교하면 NG 사진 90장 중 23장에서 검출이 없었는데, 상당수는 라벨에도 결함이 없다. NG 는 **부품 단위 판정**으로 보이므로, 에이전트에서는 **부품의 5장 중 하나라도 불량이면 불량**으로 묶어 판정하는 것이 맞다.
