# 01. 목표와 배경

## 1. 최종 목표

**국립창원대 AI Agent 해커톤 TOPIC 01 「부품 불량 사진 분석 AI Agent」** 를 만든다.

- 현장 문제: 작업자가 Scratch·Dent·Burr 같은 외관 불량을 눈으로 확인하고, 원인·조치를 정리해 보고서를 쓰는 데 시간이 많이 든다.
- 에이전트 목표: **불량 사진 한 장으로 유형 판정부터 보고서 초안까지** 만든다.
- 핵심 원칙(주최 측): 완전 자동화보다 **"작업자가 신뢰할 수 있는 보조 Agent"**. 중요한 판단은 작업자가 확인하고 확정한다 (Human-in-the-loop).
- 실행 환경 목표: 노트북에서 **Ollama + Qwen 으로 인터넷 없이 내부에서 동작**하는 에이전트.

## 2. 주최 측이 정의한 워크플로우와 우리 구현의 대응

| 해커톤 STEP | 하는 일 | 우리 구현 | 상태 |
|---|---|---|---|
| STEP 1 사진 분석 | 불량 영역을 찾고 위치 표시 | **YOLO 모델** (PCB 검출 / 금속 표면 세그멘테이션) | ✅ 모델 완료 |
| STEP 2 불량 유형 선택 | 유형 제안 → 작업자가 선택·수정 | YOLO 클래스 + 신뢰도 → 화면에서 작업자 확인 | 🔲 화면 개발 필요 |
| STEP 3 원인 후보 | 유형·공정 정보로 원인 후보 | `knowledge/defect_taxonomy_pcb.yaml` 조회 (+ RAG 확장 가능) | ✅ PCB 초안 / 🔲 금속 미작성 |
| STEP 4 조치 방법 | 원인별 조치·재발 방지 | 같은 taxonomy 파일의 actions | ✅ PCB 초안 |
| STEP 5 보고서 | 사진·유형·원인·조치 보고서 | Qwen 이 문장 작성 + 코드가 양식에 채움 | 🔲 개발 필요 |

해커톤 안내서의 Agent 개념(① 본다 → ② 찾는다 → ③ 판단한다 → ④ 작성한다)에 그대로 대응한다.

## 3. 핵심 설계 결정과 이유

### 3-1. 역할 분담: "보는 것은 YOLO, 쓰는 것은 LLM, 절차는 코드"
- 결함이 매우 작다 (PCB 결함은 이미지의 약 0.06%, 640px 기준 15×15px 정도). 범용 LLM 은 이런 결함을 정확히 찾지 못한다 → **위치·유형은 전용 검출 모델(YOLO)** 이 맡는다.
- 노트북에서 돌릴 작은 로컬 LLM(Qwen 4~8B)은 절차를 빼먹거나 사실을 지어내기 쉽다 → **판정 규칙과 순서는 코드**로 고정하고, **LLM 은 근거가 주어진 상태에서 설명·문장 작성만** 맡긴다.

### 3-2. 정상 판정 방식: "기준 신뢰도 이상 검출이 없으면 정상"
- 별도의 '정상' 클래스를 만들지 않는다.
- 3단계 판정 (기준값은 `defect_taxonomy_pcb.yaml` 의 `judgment` 에 있음):

| 조건 | 판정 | 에이전트 동작 |
|---|---|---|
| 신뢰도 0.25 이상 검출 없음 | 정상 | 통과, 이력 기록 |
| 0.25~0.5 사이 검출만 있음 | 재검 필요 | 의심 영역 표시, 작업자 확인 요청 |
| 0.5 이상 검출 있음 | 불량 | 원인·조치 붙여 보고서 초안 |

- 이 판정이 믿을 만하려면 **정상 이미지로 오탐률을 측정**해야 한다. PCB 데이터셋에는 정상 이미지가 없어 측정하지 못했고, 금속(MSDD) 데이터셋에서는 측정했다 (03 문서).

### 3-3. 지식은 라벨과 분리
- YOLO 라벨에는 "어떤 결함이 어디에" 만 둔다.
- 한글명·심각도·원인·조치는 **별도 YAML 파일** 로 관리한다 → 모델을 재학습하지 않고도 내용을 바꿀 수 있고, 주최 측 「불량 유형 정의서」를 받으면 이 파일만 교체하면 된다.

### 3-4. 즉시 조치는 사람이 한다
- 보드 격리, 수리, 폐기, 실측 같은 **물리적 조치와 최종 결정은 작업자**.
- 에이전트는 판정 기록, 보류 등록, 담당자 알림, 이력 조회, 작업 지시 체크리스트, 보고서 초안처럼 **시스템 작업**을 맡는다.

## 4. 왜 모델이 두 개인가

| 모델 | 데이터 | 목적 |
|---|---|---|
| PCB 결함 검출 (`pcb_v2_yolo11s.pt`) | PCB 결함 8종 공개 데이터 | 처음 확보한 데이터로 **파이프라인 전체를 먼저 검증**하기 위한 프로토타입 |
| 금속 표면 세그멘테이션 (`msdd_v1_yolo11s_seg.pt`) | 금속 부품 표면 결함 6종 공개 데이터 | 해커톤 예시(Scratch·Dent·Burr 등 **부품 외관 불량**)에 더 가까운 도메인. 정상 이미지가 있어 판정 성능 측정 가능 |

주의: 주최 측은 [불량 사진 샘플]·[불량 유형 정의서]·[보고서 양식]을 별도로 제공한다고 했다.
**실제 대회 데이터가 오면 그 데이터로 다시 학습**하게 될 가능성이 높으므로, 지금 모델들은 "파이프라인을 미리 완성해 두기 위한 출발점" 으로 본다.
지금 만든 데이터 정리·평가 스크립트(`tools/`)는 새 데이터에도 그대로 쓸 수 있다.
