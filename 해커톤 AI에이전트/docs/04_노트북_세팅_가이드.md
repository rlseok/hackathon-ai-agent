# 04. 노트북 세팅 가이드 (아무것도 설치되지 않은 Windows 노트북 기준)

목표: 이 패키지의 모델을 노트북에서 실행하고, **Ollama + Qwen** 을 로컬에서 돌릴 수 있게 만든다.
예상 소요: 30분~1시간 (Qwen 모델 다운로드 시간 포함). 모델 다운로드에만 인터넷이 필요하고, 이후에는 오프라인으로 동작한다.

---

## 0단계. 노트북 사양 확인

`설정 → 시스템 → 정보` 에서 **설치된 RAM** 을, `작업 관리자 → 성능` 에서 **GPU** 를 확인한다.

| 사양 | YOLO | Qwen 추천 크기 |
|---|---|---|
| RAM 8GB, GPU 없음 | CPU 로 사진 1장 0.2~0.5초 (충분) | 4B 이하 (예: `qwen3:4b`) |
| RAM 16GB, GPU 없음 | 동일 | 7~8B (예: `qwen3:8b`) — 답변이 다소 느림 |
| NVIDIA GPU (VRAM 6GB 이상) | GPU 사용 가능 | 7~8B 가 빠르게 동작 |

## 1단계. 패키지 복사

1. USB 등으로 `defect_agent_package` 폴더를 노트북에 복사한다.
2. **추천 위치: `C:\defect_agent_package`** — 경로에 한글이나 공백이 없으면 각종 도구에서 오류가 덜 난다.
   (데스크톱에서는 사용자 이름이 `연구실` 이라 경로 문제가 여러 번 있었다.)

## 2단계. Python 설치

1. https://www.python.org/downloads/ 에서 **Python 3.12.x** (Windows installer 64-bit) 다운로드.
   - 3.14 같은 최신 버전은 일부 패키지가 아직 불안정할 수 있어 3.12 를 권장한다.
2. 설치 첫 화면에서 **"Add python.exe to PATH" 체크** 후 Install Now.
3. 확인 (PowerShell 새 창):
   ```
   python --version
   ```
   `Python 3.12.x` 가 나오면 성공.

## 3단계. 가상환경 만들기

PowerShell 에서:
```
cd C:\defect_agent_package
python -m venv .venv
```
활성화:
```
.\.venv\Scripts\Activate.ps1
```
- "이 시스템에서 스크립트를 실행할 수 없으므로…" 오류가 나면 먼저 아래를 실행하고 `Y` 입력 후 다시 활성화:
  ```
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  ```
- 성공하면 프롬프트 앞에 `(.venv)` 가 붙는다. **이후 모든 명령은 `(.venv)` 상태에서 실행.**

## 4단계. 파이썬 패키지 설치

**NVIDIA GPU 가 있으면 먼저** PyTorch GPU 버전을 설치한다 (없으면 이 줄은 건너뛴다).
```
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
```
- RTX 50 시리즈처럼 최신 GPU 는 `cu126` 대신 `cu128` 을 사용한다.

그다음 공통으로:
```
pip install -r requirements.txt
```
GPU 확인 (GPU 가 있는 경우만, `True` 가 나오면 성공):
```
python -c "import torch; print(torch.cuda.is_available())"
```

## 5단계. Ollama 설치와 Qwen 모델 받기

1. https://ollama.com/download 에서 Windows 용 설치 파일을 받아 설치한다. 설치 후 백그라운드에서 자동 실행된다.
2. 확인:
   ```
   ollama --version
   ```
3. Qwen 모델 받기 (0단계 표 참고, 하나만 받아도 된다):
   ```
   ollama pull qwen3:8b
   ```
   - 메모리가 8GB 면 `qwen3:4b`.
   - **사진을 LLM 이 직접 보게** 하려면 비전 모델이 필요하다. Ollama 라이브러리(https://ollama.com/library)에서 Qwen 비전 모델(예: `qwen2.5vl:7b`, `qwen3-vl` 계열)의 현재 이름을 확인해 받는다. 처음에는 텍스트 모델만으로 충분하다 (05 문서 참고).
4. 동작 확인:
   ```
   ollama run qwen3:8b "PCB 단선 불량의 원인을 한 문장으로 말해줘"
   ```
   답이 나오면 성공. 종료는 `/bye`.

## 6단계. 전체 확인

```
python check_setup.py
```
확인하는 항목:
1. Python 버전, 필수 패키지 설치 여부
2. 두 YOLO 모델 로드 → 우수 사례 원본 이미지로 시험 추론 → 결과 이미지를 `check_output/` 에 저장
3. Ollama 서버 연결, 받아둔 모델 목록, Qwen 짧은 응답 테스트

모든 항목이 `[OK]` 면 에이전트 개발을 시작할 수 있다 → [05_에이전트_개발_가이드.md](05_에이전트_개발_가이드.md)

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `python` 명령을 찾을 수 없음 | 설치 시 PATH 체크를 안 함 → Python 재설치하며 체크, 또는 `py` 명령 사용 |
| `Activate.ps1` 실행 불가 | 3단계의 `Set-ExecutionPolicy` 실행 |
| `FileNotFoundError` (경로) | 명령을 패키지 폴더가 아닌 곳에서 실행 → `cd C:\defect_agent_package` 후 다시 실행 |
| 모델 로드 오류 (`ultralytics` 관련) | 모델은 Ultralytics 8.4.177 로 학습됨 → `pip install -U ultralytics` |
| `ollama` 연결 실패 | 작업 표시줄 트레이에 Ollama 가 실행 중인지 확인, 또는 `ollama serve` |
| Qwen 답변이 매우 느림 | 모델이 메모리보다 큼 → 한 단계 작은 모델(`qwen3:4b`) 사용 |
| 큰 실사진에서 결함을 못 잡음 | 결함이 너무 작아짐 → `imgsz=1280` 또는 사진을 잘라서 추론 |
